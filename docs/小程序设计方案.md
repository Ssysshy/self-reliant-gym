# 撸铁不求人 · 微信小程序设计方案

## 一、用户要解决的三个问题

| 用户在健身房的问题 | 产品如何回答 | 用户完成的动作 |
| --- | --- | --- |
| 今天练什么？ | 登录后按经验选择免费周模板或手动排周计划，在「训练计划」查看今天的安排。 | 选择模板或自己排一周，开始今天的训练 |
| 眼前的器材怎么用，能练哪里？ | 器材详情展示调节步骤、示意图和可练动作。每个动作展示主要及辅助肌群、准备姿势、动作步骤和常见错误。 | 从器材找到动作，或从动作反查器材 |
| 我做到哪了，什么时候做下一组？ | 执行页保留当前动作、已完成组数、目标组数与休息倒计时。 | 完成一组、按时返回、结束后查看实际记录 |

首版免费开放双库、模板、自定义计划、训练监督、记录和休息小游戏。PRO 的权益是按个人条件智能生成周计划。拍照识别器材、动作评论分别排在第二期和第三期。

## 二、从第一次打开到下一次进馆

### 首页与登录

首页参照图一。标题为「撸铁不求人」，从上到下依次放置「动作库」「器材库」「训练计划」三张整行卡片，卡片下方居中放灰色小字按钮「记录与账户」。返回首页始终使用这一布局。

| 点击入口 | 游客 | 已登录 |
| --- | --- | --- |
| 动作库、器材库 | 直接打开列表和详情，可搜索、筛选、跨库查看教学 | 直接浏览 |
| 训练计划 | 用户点击后才发起登录，成功后按计划状态分流 | 有计划则进入个人训练计划库；没有则在首页继续引导 |
| 记录与账户 | 点击后登录，成功后直达账户页 | 直达账户页；返回首页时再判断计划引导 |

首次打开以游客态展示；已有会话时恢复登录状态。取消登录留在首页。公开页面遇到会话过期仍可浏览，下次进入受保护入口时再登录。

### 已登录且尚未设置计划

1. **选择经验**。首页取得账号状态后弹出「你是健身小白，还是训练老炮？」。点「小白」或「训练老炮」后立即将选择保存到账号。已有经验记录时从对应分支继续；已有个人计划时跳过整段引导。关闭弹窗可继续浏览，同次停留不重复弹，点击「训练计划」可主动继续。
2. **小白选偏好**。弹出「我们给你准备了几个训练计划」，询问「一周几练？」和「想练哪些部位？」。周频单选，部位可多选或选「全身」。从运营已发布的免费模板中匹配，展示候选方案的完整一周、休息日及每日动作和组次。无匹配时保留已选项，允许调整条件。
3. **训练老炮**。直接进入自定义周计划编辑页，自己选训练日、部位、动作和组次，也可从免费模板开始。
4. **保存与开练**。点击「保存」成功后，将方案加入个人训练计划库并设为当前计划，立即弹出「让我们马上开练吧」，主按钮为「猛攻」。弹窗显示这次要练的部位。点「猛攻」创建或恢复训练会话，直接进入训练计时器页的第一组（恢复时定位到上次进度）；完成一组后才开始组间倒计时。今日无训练安排时取接下来最近的计划训练日。保存失败停留在预览页；开练失败可重试，关闭开练弹窗后可从训练计划继续。

### 日常训练

1. **看计划**。个人训练计划库展示已保存方案和当前计划。当前计划中优先展示进行中的训练，其次是今日安排或休息日与下次训练。训练前可查看动作做法；临时调整只影响之后开始的训练。
2. **练一组**。点击“开始训练”后，执行页展示如“坐姿划船 · 已完成 1/3 组”，预填本组目标次数，允许填写实际次数和可选重量（公斤）。点击“完成本组”只记录一次；有剩余训练时进入休息，最后一组进入结算确认。
3. **休息与监督**。休息页持续显示剩余秒数、下一个动作和组序。可安静等待、点开小游戏或提前结束休息。到时收起游戏，突出“开始下一组”。倒计时结束不会代替用户记组。
4. **收尾与回看**。可跳过动作，也可提前结束，确认页列出已完成和未完成组数。结束后看计划与实际的差异。训练计划页的本周进度按不同训练日统计，重练同一天的记录在历史中分别保留。

**首批模板内容草案**（用于产品配置，发布前由内容负责人审定动作、组次与图示）

| 模板 | 每次练哪里、练什么 |
| --- | --- |
| 每周 2 练 · 全身入门 | 周二全身 A：杯式深蹲、坐姿推胸、坐姿划船。周五全身 B：腿举、高位下拉、器械推肩。 |
| 每周 3 练 · 上肢／下肢／全身 | 周一上肢：坐姿推胸、坐姿划船。周三下肢：腿举、坐姿腿弯举。周六全身：杯式深蹲、高位下拉、坐姿推胸。 |
| 每周 4 练 · 上下肢交替 | 周一上肢 A：坐姿推胸、坐姿划船。周二下肢 A：腿举、坐姿腿弯举。周四上肢 B：高位下拉、器械推肩。周六下肢 B：杯式深蹲、臀桥。 |

未列出的星期为休息日。每个模板动作都从内容库读取目标组数、每组次数及休息档位的模板配置，用户采用后获得自己的副本。

## 三、页面与视觉

首页采用纵向卡片导航，二级页从顶部返回。训练中固定底部主操作，单手即可记组。

| 页面 | 必须展示的内容与操作 |
| --- | --- |
| 个人训练计划库／周计划 | 今日部位、动作数、开始或继续按钮，本周计划日和完成情况。周视图只保留入口：选免费模板、PRO 智能生成、进入自定义周计划。 |
| 自定义周计划 | 独立编辑页（`pages/custom`）：填计划名称、切换训练日、逐日添加动作并设置组次／次数／组间休息，可保存单个训练日再排下一天；保存后设为当前计划，并直接询问是否马上开练。从计划库可带模板、智能草案或已有计划进入，改已有计划是原地覆盖。 |
| 资料库／详情 | 动作库与器材库共用一套双列布局，配色与全站一致（白底、黑色选中态、细线描边卡片，不引入主题色）：顶部为固定的搜索框与器材分类横向筛选（全部／器械／杠铃／哑铃／史密斯／绳索／弹力带／徒手），下方左侧部位、右侧卡片各自独立滚动。部位为可折叠的两级菜单（胸、背、肩、二头、三头、小臂、腿、小腿、臀部、腹部、斜方肌、有氧；胸、背、肩、腿可展开为细分肌群），默认只展开当前部位。动作卡片含封面图、名称、细分肌群与器材分类标签，点击进入详情（器材调节、动作步骤、辅助肌群、常见错误）。器材库沿用同一布局，左侧换成具体器材。无匹配时提示清除筛选。 |
| 本次训练（开练前清单） | 从计划页或首页进入后先看整场：训练日部位、动作数、总组数、预计时长；每个动作为一张卡（缩略图、名称、细分肌群与器材、组数、每组次数、组间休息），点卡片可先看教学，点「从这开始」则把游标移到该动作第一组（前面的组记为跳过）。同一训练日有未完成进度时，顶部提示已练组数并给出「重新开始」，主按钮变「继续训练」；底部固定「返回计划／开始训练」，避免开练前不知道这次要练什么。 |
| 智能计划 | 选择目标、每周训练日、单次可用时间、现有器材。普通用户进入会员页；会员先看可编辑草案，确认采用后才切换当前计划。条件不足时指出需要调整的项目。 |
| 执行／休息／结算 | 一次突出一个动作，教学从当前页打开并可原位返回。完成一组后原地弹出休息倒计时（环形进度 + 剩余秒数 + 下一组是什么），可跳过、±10 秒或收起成底部一条；跳过显示剩余组数，提前结束或零完成退出均需确认。 |
| 记录与账户 | 按图二排列：顶部返回和标题，依次为「我的训练记录」（本月及累计训练）、「个人训练计划库」、「PRO 会员」（开通状态及有效期）、「微信账号同步」（展示当前账号及待同步状态），下方为反馈、服务协议、隐私说明和版本号。 |
| 服务协议／隐私说明 | 两页同一套排版：系统导航栏、白底、章节小标题 + 圆点正文，与全站其它二级页一致。服务协议按七条分节（服务内容、账号与使用、会员服务、知识产权、免责声明、服务变更与终止、协议生效），页脚注明更新日期；隐私说明沿用条款分组。两页均为纯文本，不引用外部链接。 |
| 我的训练记录 | 按日期倒序列出部位、时长、实际组数和完成情况；详情保留训练当时的动作与目标。 |
| PRO 会员／我的订单 | 按参考图四纵向排列三张套餐卡，左侧期限和权益，右侧价格及“开通”。展示当前有效期、订单状态和支付问题入口。 |

沿用参考图的白底、黑色标题、灰色说明、细线图标和浅灰描边卡片。页面左右留白 32rpx，卡片圆角 24rpx，主按钮黑底白字。进行中、已完成、待同步均有文字；训练页把大字号留给组数和倒计时。顶部避开微信胶囊，底部操作避开系统安全区。

## 四、原生实现与恢复

- **目录**：使用原生 WXML、WXSS、JSON 和 TypeScript。页面放在 `pages/`；`services/` 统一处理登录、请求、订单查询，`types/` 定义接口类型。首版使用原生组件。休息倒计时不再单独抽组件，随训练页一起写在 `pages/workout`（样式为 `.rest-*` 段）。
- **计时器**：仅提供 30、60、90 秒，默认取当前动作设置。点「完成本组」后不跳页，直接在训练页上浮出休息弹窗：环形进度 + 剩余秒数，下面写明「下一组／下一个动作 + 第几组 + 次数」，并支持跳过休息、±10 秒与收起成底部一条（收起后仍可回看当前动作）。开始休息时按账号和训练 ID 保存截止时间；页面根据截止时间算剩余秒数，离页清理刷新任务，回到前台重新计算。休息中修改档位按同一起点重算。到时短振一次并自动收窗。
- **小游戏**：首版只做“点亮出现的圆点”。用户主动在休息弹窗内进入，倒计时始终可见，可随时收起；倒计时归零即随之结束，切后台暂停游戏、休息时间继续推进。
- **断网与重入**：开始训练需联网取得动作快照。每次记组先持久化实际数据和操作编号，成功后才进入休息；失败时保留输入。弱网显示“待同步”，恢复联网后按序重传。结束操作排在未同步记组之后。换账号隔离草稿；多设备发生版本冲突时展示服务端进度，保留本机差异供确认。
- **会员**：7 天 ¥9.9、30 天 ¥29.9、365 天 ¥128，均为一次购买。商品和终端购买能力由后端返回。付款返回后查询订单，待确认时允许稍后从“我的订单”恢复；权益到账后回到原生成表单。到期后可继续执行已保存计划。

## 五、交付任务与完成条件

| 顺序 | 前端任务 | 完成条件 |
| --- | --- | --- |
| F1 | 搭原生导航，完成双库和内容详情 | 初次使用者能从任一器材找到动作、目标肌群与操作说明 |
| F2（接 F1） | 登录分流、经验弹窗、免费模板匹配、个人计划库与开练 | 账户入口登录后到达原目标；小白保存后点「猛攻」直达计时器，已设计划的账号跳过引导 |
| F3（接 F2） | 逐组记录、计时组件、小游戏、恢复与历史 | 从开始到结算可完整走通；切后台回来能定位正确组次；历史同时展示目标与实际 |
| F4（接 F2，依赖后端会员接口） | 三档套餐、订单恢复、智能草案预览及采用 | 普通用户可开通，已付订单可恢复，会员可生成并确认采用草案 |
| 第二期 | 拍照识别器材 | 主动拍照后预览，用户确认识别候选再进入器材及可练动作；识别失败可手选 |
| 第三期 | 动作详情增加“训练心得（邪修方法）” | 可发布、举报；公开区仅展示审核通过的内容，心得与正式动作教学分区 |
